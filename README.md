# Arquitetura de Computadores I — PUC Minas

Repositório com os materiais, exercícios, anotações e projetos desenvolvidos na disciplina de **Arquitetura de Computadores I**, do curso de Ciência da Computação da PUC Minas (Campus Coração Eucarístico).

**Aulas:** Terça e Sexta-feira

## Estrutura

```
├── aulas/          # Anotações de cada aula (nomeadas por data)
│   ├── template.md
│   ├── 2026-08-18-terca.md
│   └── 2026-08-21-sexta.md
├── atividades/     # Circuitos e atividades práticas (Logisim, exercícios)
│   └── somador_4_bits.circ
├── guias/          # Guias e listas de exercícios da disciplina
├── avaliacoes/     # Materiais de avaliações e provas
└── docs/           # Anotações e documentação complementar
```

## Como usar a pasta `aulas/`

Cada aula tem um arquivo `.md` nomeado como `AAAA-MM-DD-diadasemana.md`. Para uma aula nova, copie o `template.md` e preencha:

- Resumo da aula
- Conceitos importantes
- Exercícios feitos em aula
- Dúvidas / pontos a revisar
- Tarefas para a próxima aula

## Conteúdo

- **atividades/somador_4_bits.circ** — Circuito somador de 4 bits (ripple-carry adder) implementado no Logisim, com construção de tabela verdade e equações booleanas de full adder.

## Tecnologias

- Logisim (simulação de circuitos digitais)
