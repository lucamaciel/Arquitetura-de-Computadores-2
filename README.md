# Arquitetura de Computadores I — PUC Minas

Repositório com os materiais, exercícios e projetos desenvolvidos na disciplina de **Arquitetura de Computadores I**, do curso de Ciência da Computação da PUC Minas (Campus Coração Eucarístico).

## Estrutura

```
├── logisim/       # Circuitos digitais desenvolvidos no Logisim
├── guias/         # Guias e listas de exercícios da disciplina
├── avaliacoes/    # Materiais de avaliações e provas
└── docs/          # Anotações e documentação complementar
```

## Conteúdo

- **logisim/somador_4_bits.circ** — Circuito somador de 4 bits (ripple-carry adder) implementado no Logisim, com construção de tabela verdade e equações booleanas de full adder.

## Tecnologias

- Logisim (simulação de circuitos digitais)
